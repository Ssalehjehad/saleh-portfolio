# Saleh Abu Zayed Portfolio

Static portfolio site for Saleh Abu Zayed.

## Files

- `index.html` - portfolio page
- `styles.css` - responsive styling
- `script.js` - sticky header and active navigation behavior
- `assets/saleh-profile.jpg` - profile image
- `Saleh_Abu_Zayed_CV_Final.pdf` - recruiter-facing CV
- `Saleh_Abu_Zayed_CV_ATS.pdf` - ATS-friendly CV

## Deploy

This site has no build step. Deploy the folder as a static site on GitHub Pages, Netlify, Vercel, Cloudflare Pages, or any web server.

For a local preview, open `index.html` in a browser.
